# 미션 6. 예약 실행 & 스킬 패키지 공유 (Lv.6 · 10분)

한 번 만들면 알아서 일하고, 동료에게 그대로 건넬 수 있게 만듭니다.

## 1. 완성 패키지 살펴보기 — `gongmun-helper/`
```
gongmun-helper/
├ SKILL.md      업무 인수인계서 (Lv.4 스킬 3개 + Lv.5 예외 규칙 4개)
├ checklist.md  검토 기준
├ assets/       학교 양식(주간업무보고_양식.hwpx)
├ scripts/      hwpx_tool.py
└ examples/     입력 · 결과 예시 안내
```
- `gongmun-helper.zip` 을 **Customize → Skills** 에 올립니다.
- Cowork **새 작업**(작업 폴더 `Lv5_검증`)에서 한 번 실행해 봅니다.

```
gongmun-helper 스킬로 기준일 2026. 11. 2.(월) 공문을 처리해 줘.
```

## 2. 예약 실행 — 매주 월요일 08:00
[`예약실행_프롬프트.md`](예약실행_프롬프트.md) 의 문장을 복사해 씁니다.

| 방법 | 순서 |
|---|---|
| 방법 1 · 채팅에서 | `/schedule` 입력 → 작업 설명 붙여 넣기 → 주기(매주 월 08:00)와 작업 폴더 선택 |
| 방법 2 · 메뉴에서 | **Scheduled → New task** → 작업 내용 · 반복 주기 · 작업 폴더 설정 |

- 결과는 **Scheduled** 함에서 확인합니다.
- ⚠ 내 PC 폴더를 쓰는 예약 작업은 **PC와 앱이 켜져 있어야** 실행됩니다. 요금제·기관 정책에 따라 제한될 수 있습니다.

## 3. 공유
- 스킬 폴더째 zip으로 묶어 동료에게 전달 → 받은 사람은 **Customize → Skills → 업로드**.
- 내 스킬을 zip으로 묶을 때:

```
내가 고친 gongmun-helper 스킬 폴더를 업로드용 zip으로 묶어서 Lv6_자동화공유 폴더에 저장해 줘.
```
