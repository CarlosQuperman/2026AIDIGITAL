# 예약 실행 프롬프트

## 매주 월요일 08:00 — 공문 폴더 정리 → 이번 주 할 일 요약

```
gongmun-helper 스킬을 사용해.
기준일은 오늘 날짜로 하고, 작업 폴더의 input 폴더 공문을 처리해 줘.
결과 파일 3개(공문목록 xlsx, 이번주할일 md, 주간업무보고 hwpx)는 output 폴더에
'날짜_업무명_버전' 이름으로 저장하고, 마지막에 아래 형식으로 요약해 줘.

- 이번 주 마감: N건 (가장 급한 것 1건)
- 확인이 필요한 공문: N건 (이유)
- input 원본은 수정하지 않았는지 확인 결과
```
