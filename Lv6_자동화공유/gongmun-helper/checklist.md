# 검토 체크리스트

| 번호 | 점검 항목 | 이렇게 확인한다 |
|---|---|---|
| 1 | 원본 대비 누락이 없다 | `input/` 파일 수와 목록 건수를 비교한다. 붙임 파일의 내용까지 반영됐는지 본다. |
| 2 | 날짜·숫자가 원본과 일치한다 | 마감일, 시각, 요일, 인원, 금액을 원본 문장과 하나씩 대조한다. |
| 3 | 원본에 없는 내용이 없다 | 원본에 없는 마감일, 제출물, 연락처를 지어내지 않았는지 본다. |
| 4 | 개인정보가 드러나지 않는다 | 학생·교직원 이름, 연락처, 학번이 결과물에 들어가지 않았는지 본다. |

## 자주 놓치는 경우
- 마감일이 없는 공문에 날짜를 지어 넣은 경우
- 같은 문서번호의 재발송 공문을 두 건으로 센 경우
- 글자가 없는 스캔 PDF를 읽지 못하고 빠뜨린 경우
- 본문 없이 "붙임 참조"만 있는 공문의 마감일을 놓친 경우
