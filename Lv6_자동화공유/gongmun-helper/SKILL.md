# 공문 해결사 (gongmun-helper)

Lv.4의 스킬 3개(공문 정리 → 할 일 추출 → 보고 초안)를 하나로 묶고,
Lv.5에서 발견한 함정 4가지를 예외 규칙으로 더한 완성 패키지다.

## 입력
- 작업 폴더의 `input/` 공문 파일 전체(hwpx, pdf, docx, 붙임 파일 포함)
- 기준일: 사용자가 말한 날짜, 없으면 실행한 날짜
- 양식: `assets/주간업무보고_양식.hwpx`
- 읽기 도구: hwpx는 `python scripts/hwpx_tool.py text <파일>`, pdf는 `pdftotext` 또는 `pypdf`

## 절차
1. **정리**: `input/` 을 읽어 공문별로 문서번호, 발신, 제목, 시행일, 마감일, 제출물, 제출 방법을 뽑아 `work/공문목록.json` 에 저장한다.
2. **예외 처리**: 아래 '예외 규칙'을 적용한다.
3. **목록**: `output/<기준일8자리>_공문목록_v1.xlsx` 를 만든다. (열: 번호 | 파일명 | 문서번호 | 발신 | 제목 | 시행일 | 마감일 | 제출물 | 제출 방법 | 비고)
4. **할 일**: 기준일 기준으로 `output/<기준일8자리>_이번주할일_v1.md` 를 만든다. (이번 주 / 다음 주 / 그 이후 / 확인이 필요한 공문)
5. **보고 초안**: `assets/주간업무보고_양식.hwpx` 를 `fill` 해서 `output/<기준일8자리>_주간업무보고_v1.hwpx` 를 만든다. (마감 임박 8건 → 업무1~8, 나머지 → 다음주1~3, 확인 필요 공문 → 확인필요)
6. **자체 점검**: `checklist.md` 의 4개 항목을 스스로 점검하고, 결과를 `log.md` 에 적는다.
7. 결과 파일 3개와 '확인 필요' 목록을 사용자에게 보고한다.

## 예외 규칙 (Lv.5 함정에서 추가)
- **마감일 없는 공문**: 마감일을 지어내지 않는다. 마감일 칸은 비우고 비고에 "마감일 없음(확인 필요)". 할 일 목록에서는 '확인이 필요한 공문' 구역에 넣는다.
- **중복 공문**: 문서번호와 제목이 같으면 1건으로 센다. 비고에 "재발송 중복: <다른 파일명>".
- **스캔 이미지 PDF**: 글자를 뽑았는데 비어 있으면 이미지로 읽기를 시도한다. 읽었으면 비고에 "스캔본: 원본 대조 필요", 못 읽었으면 마감일을 비우고 '확인 필요'로 분리한다.
- **붙임만 있는 공문**: 본문에 마감·제출물이 없고 "붙임"만 있으면 같은 번호의 붙임 파일(예: `공문14_붙임1_…`)을 읽어 채운다. 비고에 "붙임에서 확인". 붙임 파일은 목록에 따로 세지 않는다.

## 폴더 규칙
- `input/` 은 읽기만 한다. 수정·이동·삭제 금지.
- 중간 파일은 `work/`, 결과는 `output/` 에만 저장한다.
- 파일명은 `날짜_업무명_버전` (예: `20261102_공문목록_v1.xlsx`). 다시 만들면 v2, v3으로 올리고 이전 버전은 지우지 않는다.
- `log.md` 에 처리 건수, 실패 건수와 이유, 예외 규칙 적용 내역을 남긴다.

## 완료 기준
- 결과 파일 3개와 `log.md` 가 생겼다.
- `checklist.md` 4개 항목이 모두 '통과' 또는 '확인 필요(사유)'로 기록됐다.

## 사람 검토
- 담당 교사가 '확인 필요' 공문과 스캔본을 원본과 대조한다.
- 공문 접수·회신·결재·제출은 사람이 한다.
