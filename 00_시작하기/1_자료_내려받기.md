# 1. 실습 자료 내려받기

## 방법
1. 저장소 주소로 들어갑니다: https://github.com/CarlosQuperman/2026AIDIGITAL
2. 초록색 **Code** 버튼 → **Download ZIP** 을 누릅니다.
3. 받은 `2026AIDIGITAL-main.zip` 을 **바탕화면** 또는 **문서** 폴더에 압축 해제합니다.
4. 압축을 푼 `2026AIDIGITAL-main` 폴더를 열어 아래 폴더가 보이는지 확인합니다.

```
00_시작하기  가정통신문  Lv1_그냥시키기  Lv2_스킬만들기  Lv3_양식지키기
Lv4_스킬연결  Lv5_검증  Lv6_자동화공유  완성본  연수자료
```

## 자주 생기는 문제
| 증상 | 해결 |
|---|---|
| 압축을 풀었더니 파일 이름이 깨진다 | 반디집 등 다른 압축 프로그램으로 다시 풉니다. |
| 압축 안에 폴더가 한 번 더 있다 | 안쪽 `2026AIDIGITAL-main` 폴더를 작업 폴더로 씁니다. |
| hwpx 파일이 안 열린다 | 한글 2018 이상에서 열립니다. 실습은 열어 보지 않아도 진행할 수 있습니다. |

## 폴더를 고를 때 기억할 것
- Lv.1 ~ Lv.3: Claude Desktop **Cowork 작업 폴더 = `2026AIDIGITAL-main` 전체**
- Lv.4: 작업 폴더 = `Lv4_스킬연결`
- Lv.5: 작업 폴더 = `Lv5_검증`
- Lv.6: 작업 폴더 = `Lv5_검증` (함정까지 들어 있는 폴더로 완성 패키지를 실행)
