# 2. Claude Desktop 준비

> 화면 메뉴 이름은 앱 버전에 따라 조금 다를 수 있습니다. 비슷한 이름의 메뉴를 찾아 주세요.

## ① 설치와 로그인
- https://claude.ai/download 에서 Claude Desktop을 설치하고 로그인합니다.
- Cowork, 스킬, 예약 실행은 요금제와 기관 정책에 따라 쓸 수 있는 범위가 다릅니다. 연수 전에 확인해 주세요.

## ② 코드 실행 켜기 (스킬 사용에 필수)
- **설정 → 기능(Capabilities)** 에서 **코드 실행 및 파일 생성** 을 켭니다.
- 꺼져 있으면 스킬이 보이지 않거나 hwpx·xlsx 파일을 만들지 못합니다.

## ③ Cowork에서 작업 폴더 지정
1. 왼쪽 위 **Cowork** 탭을 엽니다.
2. 작업 폴더 선택에서 압축을 푼 `2026AIDIGITAL-main` 폴더를 고릅니다.
3. 첫 메시지로 확인해 봅니다.

```
이 폴더에 어떤 하위 폴더와 파일이 있는지 목록으로 보여 줘.
```

## ④ 스킬 올리기 (Lv.2부터)
1. **Customize → Skills** 로 들어갑니다. (버전에 따라 설정 → 기능 → Skills)
2. **업로드(+)** 를 누르고 스킬 zip 파일을 고릅니다.
   - 예: `Lv2_스킬만들기/skills/newsletter-writer.zip`
3. 목록에 스킬 이름이 보이고 켜져 있으면 준비 끝입니다.
4. 같은 이름의 스킬을 고쳐서 다시 올릴 때는 기존 스킬을 지우고 올립니다.

## ⑤ 스킬 부르기
- 요청이 스킬 설명(description)과 맞으면 **자동으로** 불러 씁니다.
- 확실하게 쓰고 싶으면 이름을 넣어 지시합니다.

```
newsletter-writer 스킬로 가정통신문 폴더의 넷마블 운영계획서를 가정통신문으로 만들어 줘.
```

## ⑥ 스킬 만들기 도우미
- 대화에서 "이 설계 카드로 스킬을 만들어 줘"라고 요청하면 Claude가 SKILL.md와 폴더를 만들어 zip으로 줍니다.
- 받은 zip을 ④의 방법으로 올립니다.

## ⑦ 예약 실행 (Lv.6)
- 채팅에서 `/schedule` 을 입력하고 작업을 설명하거나, **Scheduled → New task** 에서 만듭니다.
- 내 PC 폴더를 쓰는 예약 작업은 **PC와 앱이 켜져 있어야** 실행됩니다.
