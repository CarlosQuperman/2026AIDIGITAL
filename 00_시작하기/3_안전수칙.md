# 3. 꼭 지킬 안전 수칙 5가지

| 번호 | 수칙 | 실천 방법 |
|---|---|---|
| 1 | 실제 학생·교직원 개인정보는 넣지 않는다 | 가상 데이터로 실습, 실제 업무는 가림 처리(예: 김OO, ○○○) |
| 2 | 원본이 아닌 복사본으로 작업한다 | `input/` 원본 폴더는 읽기만 |
| 3 | 발송·결재·제출은 반드시 사람이 한다 | 에이전트는 초안까지 |
| 4 | 결과는 원본과 대조한다 | 날짜·요일·숫자·이름은 특히 꼼꼼히 |
| 5 | 기관 보안 지침을 먼저 따른다 | 업무망·인터넷망 구분, 허용된 도구만 사용 |

## 이 저장소의 자료
- 공문은 모두 **실습용 가상 공문**(OO교육지원청 → OO학교)입니다.
- `가정통신문/` 의 운영계획서와 신청서는 실제 학교 행사 자료이며, 담당 교사·협력 교사 외 개인정보는 없습니다.
- 본인 학교 자료로 실습할 때는 개인정보를 먼저 지우거나 가린 사본을 쓰세요.
