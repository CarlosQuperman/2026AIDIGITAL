# 행사 원스톱 패키지 스킬

## 입력
- 행사 운영계획서 1개(hwpx, docx, pdf). hwpx는 `python scripts/hwpx_tool.py text <파일>` 로 읽는다.
- 양식 4종(`assets/`):
  - `가정통신문_양식.hwpx` : 학부모용 참가 신청서
  - `안전점검표_양식.hwpx` : 현장체험학습 안전점검표
  - `안전교육확인서_양식.hwpx` : 사전 안전교육 확인서(학생 서명용)
  - `결과보고서_양식.hwpx` : 결과보고서 틀(행사 후 작성)

## 절차
1. 운영계획서에서 공통 값(행사명, 일시, 장소, 대상, 인솔 교사, 사전교육, 일정표, 예산, 준비물)을 한 번만 뽑아 정리한다.
2. 양식마다 `python scripts/hwpx_tool.py fields assets/<양식>.hwpx` 로 빈칸 이름을 확인한다.
3. 양식마다 `값_<문서>.json` 을 만든다(아래 문서별 규칙).
4. 양식마다 `python scripts/hwpx_tool.py fill assets/<양식>.hwpx 값_<문서>.json output/<행사명>_<문서>.hwpx`
5. 네 문서의 "[확인 필요]" 목록을 한 표로 모아 사용자에게 보고한다.

## 공통 규칙
- 양식 구조는 바꾸지 않고 빈칸만 채운다. 표의 행 수와 칸 합치기를 바꾸지 않는다.
- 계획서에 없는 내용은 지어내지 않는다. 모르는 칸은 키를 빼서 "[확인 필요]"가 들어가게 한다.
- 날짜는 `2026. 12. 13.(토)` 형식으로 쓰고, 요일이 달력과 다르면 사용자 보고에 적는다.
- 학생 이름·학번·연락처는 넣지 않는다.

## 문서별 규칙
- 가정통신문: `newsletter-writer` 스킬과 같은 규칙. 인사말 2~3문장, 일정표 7행(남는 행은 `""`).
- 안전점검표: '확인' 칸은 사람이 직접 표시하므로 채우지 않는다. `비고N` 에는 계획서에서 확인되는 근거만 짧게 쓰고(예: "사전교육 12. 11. 16:30 컴퓨터실"), 근거가 없으면 `""`.
- 안전교육확인서: 교육 일시·장소·교육자는 계획서의 '안전교육 및 사전교육' 항목에서 가져온다. 학생 서명 표는 비워 둔다.
- 결과보고서: 행사 전에 만드는 틀이다. 운영 내용·예산 계획액은 계획서에서 채우고, 집행액·성과·개선점·작성일은 키를 빼서 "[확인 필요]"로 둔다.

## 완료 기준
- `output/` 에 hwpx 4개가 생기고, 각각 원본 양식과 표·서식이 같다.
- 모르는 칸은 모두 "[확인 필요]"로 남아 있고, 그 목록을 보고했다.

## 사람 검토
- 담당 교사가 4개 문서를 한글에서 열어 원본 양식과 나란히 비교한다.
- 안전점검표 '확인' 칸 표시, 결재, 발송은 사람이 한다.
