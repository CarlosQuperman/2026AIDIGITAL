# 미션 3. 행사 원스톱 패키지 (Lv.3 · 제한 시간 20분)

학교 문서는 양식이 생명입니다. 운영계획서 **하나**로 행사 서류 **네 가지**를 학교 양식 그대로 만듭니다.

## 입력 — 넷마블 게임 박물관 운영계획서
`가정통신문/2026학년도 AI·SW 꿈키움 현장체험학습 운영계획(넷마블 게임 박물관) .hwpx`

| 행사 개요 | 내용 |
|---|---|
| 행사명 | AI·SW 꿈키움 넷마블 게임 박물관 현장체험학습 |
| 일시 | 2026. 12. 13. 08:00 ~ 19:30 |
| 장소 | 넷마블 게임 박물관, 라운지엑스 성수 본점 |
| 대상 | 2학년 9명 |
| 준비물 | 필기도구, 비상약, 물 |

## 결과 — hwpx 4종 (`skills/event-package/assets/` 양식)
| 문서 | 양식 파일 |
|---|---|
| 가정통신문(참가 신청서) | `가정통신문_양식.hwpx` |
| 안전점검표 | `안전점검표_양식.hwpx` |
| 사전 안전교육 확인서 | `안전교육확인서_양식.hwpx` |
| 결과보고서 틀 | `결과보고서_양식.hwpx` |

## 순서
1. `skills/event-package.zip` 을 **Customize → Skills** 에 올립니다.
2. Cowork(작업 폴더: `2026AIDIGITAL-main`)에서 요청합니다.

```
event-package 스킬로 가정통신문 폴더의 넷마블 게임 박물관 운영계획서를 바탕으로
행사 서류 4종을 만들어 Lv3_양식지키기/output 폴더에 저장해 줘.
```

3. 결과 파일을 한글에서 열어 `assets/` 의 원본 양식과 **나란히** 비교합니다.
   - 표가 깨졌나? 서식이 바뀌었나? 내용을 지어냈나?
4. 문제를 하나 찾으면 [`고치기루프_기록지.md`](고치기루프_기록지.md) 에 적고, SKILL.md 맨 아래 **'고치기 루프로 추가된 규칙'** 에 규칙 한 줄을 추가합니다.

```
event-package 스킬의 SKILL.md 맨 아래 '고치기 루프로 추가된 규칙'에
"<내가 찾은 규칙>" 을 추가하고, 스킬 zip을 다시 만들어 줘.
```

5. 새 zip을 다시 올리고(기존 스킬 삭제 후 업로드) **같은 입력으로 재실행**합니다.

## 완료 조건
- [ ] 4개 모두 원본 양식 그대로(표 행 수·칸 합치기·서식 유지)
- [ ] 빈칸만 채웠고, 모르는 건 `[확인 필요]` 로 남았다
- [ ] 고치기 루프를 1회 이상 돌렸다(규칙 1줄 추가 → 재실행)

## 빠른 분은
- 내 학교 양식을 hwpx로 저장(한글 → 다른 이름으로 저장 → HWPX)하고, 바꾸고 싶은 칸에 `{{빈칸이름}}` 을 적어 `assets/` 에 넣어 보세요.

## 실패 1번 = 규칙 1줄
| 자주 생기는 실패 | 규칙 예시 |
|---|---|
| 표가 깨진다 | 표의 행 수와 칸 합치기를 바꾸지 않는다 |
| 날짜 형식이 제각각 | 날짜는 '2026. 12. 13.(토)' 형식으로 쓴다 |
| 연락처를 지어낸다 | 문의처는 계획서에 있는 번호만 쓴다 |
| 학생 이름이 들어간다 | 학생 이름은 '○○○'으로 가린다 |
