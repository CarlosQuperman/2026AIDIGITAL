# 미션 2. 설계 카드를 스킬로 (Lv.2 · 제한 시간 12분)

스킬 = 에이전트에게 주는 **업무 인수인계서**입니다. 5칸짜리 설계 카드를 채우면 SKILL.md가 됩니다.

## STEP 1. 설계 카드 쓰기 (4분)
- [`스킬설계카드.md`](스킬설계카드.md) 를 복사해 5칸을 채웁니다.
- 공통 예제는 **가정통신문**입니다. 입력은 `가정통신문/` 폴더의 넷마블 운영계획서, 결과는 학교 양식의 참가 신청서입니다.
- 막히면 [`설계카드_예시_가정통신문.md`](설계카드_예시_가정통신문.md) 를 봅니다.
- 짝과 카드를 바꿔 읽고 "이 카드만 보고 다른 선생님이 같은 일을 해낼 수 있는가?"에 **예**가 나오면 통과입니다.

## STEP 2. 스킬로 변환 (4분)
Cowork(작업 폴더: `2026AIDIGITAL-main`)에서 요청합니다.

```
Lv2_스킬만들기 폴더에 있는 내 설계 카드(스킬설계카드.md)로 Claude 스킬을 만들어 줘.
스킬 이름은 newsletter-writer, 양식은 Lv2_스킬만들기/skills/newsletter-writer/assets/가정통신문_양식.hwpx 를 써 줘.
완성되면 업로드할 수 있게 zip으로 만들어 줘.
```

- 받은 zip을 **Customize → Skills → 업로드** 로 올립니다. ([준비 안내 ④](../00_시작하기/2_Claude_Desktop_준비.md))
- 시간이 부족하거나 막히면 완성 예시 `skills/newsletter-writer.zip` 을 바로 올려도 됩니다.

## STEP 3. 3번 실행 (4분)
**새 대화**에서 아래 문장을 3번 보냅니다(미션 1과 같은 방법).

```
newsletter-writer 스킬로 가정통신문 폴더의 넷마블 게임 박물관 운영계획서를 가정통신문으로 만들어 줘.
결과는 Lv2_스킬만들기/output 폴더에 저장해 줘.
```

## 완료 조건
- [ ] 3번 모두 **같은 양식(A4 2쪽, 일정표, 참가 희망원)** 으로 나온다.
- [ ] 짝이 내 설계 카드를 읽고 OK 했다.
- [ ] 미션 1과 무엇이 달라졌는지 한 문장으로 말할 수 있다.

## 살펴볼 점
- 결과에 `[확인 필요]` 가 남은 칸은 어디인가요? (발행일, 제출 기한은 운영계획서에 없습니다.)
- 스킬이 요일을 점검해 보고했나요? 운영계획서의 `2026. 12. 13.(토)` 를 달력과 비교해 보세요.
