# 가정통신문(참가 신청서) 작성 스킬

## 입력
- 행사 운영계획서 1개. 예: `가정통신문/` 폴더의 넷마블 게임 박물관 운영계획 hwpx
- 사용자가 따로 준 조건(발행일, 제출 기한 등). 없으면 지어내지 않는다.
- 양식: 이 스킬의 `assets/가정통신문_양식.hwpx` (A4 2쪽, 절취선 아래 참가 희망원 포함)

## 절차
1. 운영계획서를 읽는다. hwpx는 `python scripts/hwpx_tool.py text <파일.hwpx>` 로 글자를 뽑는다.
2. 아래 값을 찾아 정리한다: 행사명, 목적, 일시, 장소, 대상, 인솔 교사, 사전교육, 예산(학생 부담 여부), 일정표(시간·내용·세부·장소·비고), 준비물, 유의 사항.
3. `python scripts/hwpx_tool.py fields assets/가정통신문_양식.hwpx` 로 양식의 빈칸 이름을 확인한다.
4. 빈칸 이름을 키로 하는 `값.json` 을 만든다(아래 작성 규칙). 예시는 `examples/넷마블_값.json`.
5. `python scripts/hwpx_tool.py fill assets/가정통신문_양식.hwpx 값.json output/가정통신문_<행사명>.hwpx`
6. 도구가 출력한 "[확인 필요]" 목록과 요일 점검 결과를 사용자에게 보고한다.

## 작성 규칙
- 양식의 표 행 수, 칸 합치기, 글꼴, 정렬을 바꾸지 않는다. hwpx 내부 XML을 직접 고치지 않고 `fill` 만 쓴다.
- 학부모가 읽는 글이므로 높임말(~합니다, ~바랍니다)로 쓴다.
- `인사말`: 행사 목적을 2~3문장으로 요약한다.
- 날짜는 `2026. 12. 13.(토) 08:00 ~ 19:30` 형식으로 쓴다. 요일은 달력으로 다시 확인하고, 계획서의 요일과 다르면 문서는 계획서대로 두되 사용자 보고에 반드시 적는다.
- 일정표는 7행이다. 일정이 7개보다 적으면 남는 행의 값을 모두 `""` 로 두고, 많으면 비슷한 항목을 합친다.
- `일정N_세부`: 세부 활동을 ` · ` 로 이어 한 줄(30자 안팎)로 쓴다.
- 계획서에 없는 정보(발행일, 제출 기한, 연락처 등)는 지어내지 않는다. 사용자가 알려 주지 않았으면 그 키를 빼서 "[확인 필요]"가 들어가게 한다.
- `참가비용`: 예산 내역이 모두 학교 예산이면 "개인 부담 없음 (…학교 예산 지원)", 학생 부담이 있으면 금액을 쓴다.
- 학생 이름, 학번, 연락처 같은 개인정보는 넣지 않는다.

## 완료 기준
- `output/` 에 hwpx 1개가 생기고, 원래 양식과 표·쪽 구성이 같다.
- 일시, 장소, 대상, 일정, 준비물, 안전 수칙이 빠짐없이 들어 있다.
- "[확인 필요]" 목록과 요일 점검 결과를 사용자에게 보고했다.

## 사람 검토
- 발송 전에 담당 교사가 날짜·요일·제출 기한·연락처를 한글(HWP)에서 열어 최종 확인한다.
- 실제 발송, 결재는 사람이 한다.
