# 스킬 설계 카드 — 예시(가정통신문)

- 스킬 이름: `newsletter-writer`
- 언제 쓰나: 학교 행사 운영계획서를 학부모용 가정통신문(참가 신청서)으로 바꿀 때

| 칸 | 질문 | 예시 답 |
|---|---|---|
| ① 입력 | 어떤 파일이 어디로 들어오나? | `가정통신문/` 폴더의 행사 운영계획서(hwpx) 1개, 학교 양식 `assets/가정통신문_양식.hwpx` |
| ② 절차 | 사람이 하던 순서대로 3~5단계 | 1. 운영계획서에서 행사명·일시·장소·대상·일정·준비물·예산을 뽑는다<br>2. 인사말을 2~3문장으로 쓴다<br>3. 학교 양식의 빈칸만 채운다(표·서식은 그대로)<br>4. `output/가정통신문_행사명.hwpx` 로 저장한다 |
| ③ 완료 기준 | 무엇이 나오면 끝인가? | A4 2쪽 hwpx 1개, 일시·장소·대상·일정·준비물·안전 수칙 빠짐없음, 계획서에 없는 내용은 `[확인 필요]` |
| ④ 개인정보 | 무엇을 가리고, 무엇을 넣지 않나? | 학생 이름·학번·연락처는 넣지 않는다(참가 희망원은 빈칸으로) |
| ⑤ 사람 검토 | 어디서 반드시 사람이 확인하나? | 발송 전 담당 교사가 날짜·요일·제출 기한·연락처를 한글에서 확인 |
