# 결과 검토 스킬 (교차 검증)

## 입력
- 원본: 작업 폴더의 `input/` (공문 파일)
- 검토 대상: `output/` 의 결과물(공문목록.xlsx, 이번주_할일.md, 주간업무보고.hwpx 등)
- 기준: 이 스킬의 `checklist.md`
- hwpx 읽기: `python scripts/hwpx_tool.py text <파일>`, pdf 읽기: `pdftotext` 또는 `pypdf`

## 절차
1. `checklist.md` 를 읽는다.
2. `input/` 의 원본을 모두 읽어 공문별 '정답 메모'(문서번호, 제목, 마감일, 제출물)를 만든다.
3. 결과물의 각 줄을 정답 메모와 대조하며 체크리스트 항목을 하나씩 판정한다.
4. `output/검토결과.md` 에 아래 형식으로 저장한다.

```markdown
# 검토 결과 (검토 대상: output/공문목록.xlsx 외 2개)

| 점검 항목 | 판정 | 근거(파일 · 위치) |
|---|---|---|
| 원본 대비 누락이 없다 | 문제 | input 15개 중 목록 13건, 공문14 붙임 미반영 |

## 고쳐야 할 점
1. …

## 스킬에 추가하면 좋은 규칙
- …
```

## 규칙
- 결과물을 직접 고치지 않는다. 찾고, 근거를 대고, 보고만 한다.
- 근거에는 원본 파일명과 문장을 함께 쓴다.
- 확신이 없으면 '확인 필요'로 판정한다.

## 완료 기준
- 체크리스트의 모든 항목에 판정과 근거가 있다.
- `output/검토결과.md` 가 생겼다.

## 사람 검토
- 최종 판단과 수정 지시는 사람이 한다.
