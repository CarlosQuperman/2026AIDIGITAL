# 미션 5. 함정을 찾아라 (Lv.5 · 제한 시간 10분)

`Lv5_검증/input/` 에는 Lv.4의 공문 10건에 **함정 4건**이 섞여 있습니다. Lv.4 파이프라인이 함정을 잡을까요?

| 함정 | 무엇을 보나 |
|---|---|
| 1. 마감일 없는 공문 | 날짜를 지어내는가? |
| 2. 중복 공문 | 같은 공문을 두 번 세는가? |
| 3. 스캔 이미지 PDF | 글자를 못 읽고 넘어가는가? |
| 4. 첨부만 있는 공문 | 본문이 없다고 빠뜨리는가? |

> 어떤 파일이 함정인지는 실습이 끝난 뒤 [`완성본/Lv5_함정정답.md`](../완성본/Lv5_함정정답.md) 에서 확인하세요.

## 순서
1. Cowork **새 작업** → 작업 폴더를 **`Lv5_검증`** 으로 지정합니다.
2. Lv.4와 같은 지시로 파이프라인을 다시 실행합니다.

```
기준일은 2026. 11. 2.(월)이야.
gongmun-organizer → todo-extractor → weekly-report 순서로 실행해서 input 폴더의 공문을 처리해 줘.
```

3. 결과를 보며 [`에이전트_점수표.md`](에이전트_점수표.md) 에 잡은 함정 · 놓친 함정을 표시합니다.
4. 놓친 함정을 **예외 규칙**으로 스킬에 추가하고 재실행합니다. **4/4가 되면 완료**입니다.

```
gongmun-organizer 스킬에 예외 규칙을 추가해 줘:
"마감일이 없는 공문은 날짜를 지어내지 말고 비고에 '마감일 없음(확인 필요)'이라고 쓴다."
스킬 zip을 다시 만들어 줘.
```

## 교차 검증 — 만드는 AI와 검토하는 AI를 나눈다 (5분)
같은 대화가 만들고 검토하면 자기 실수를 못 봅니다. **새 대화**에서 검토 스킬을 돌립니다.

1. `skills/output-reviewer.zip` 을 올립니다.
2. **새 작업**(작업 폴더 `Lv5_검증`)에서 요청합니다.

```
output-reviewer 스킬로 output 폴더의 결과물을 input 폴더 원본과 대조해서 검토해 줘.
```

3. `output/검토결과.md` 의 판정을 보고, 마지막 결정은 **사람**이 합니다.

| 단계 | 누가 | 하는 일 |
|---|---|---|
| 작성 | 대화 1 (작성 스킬) | 결과물 생성 |
| 검토 | 대화 2 (output-reviewer) | `checklist.md` 로 오류 찾기 |
| 최종 결정 | 사람 | 발송 · 결재 · 제출 |
