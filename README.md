## 오늘의 공식: y = ax + b

| 기호 | 뜻 | 오늘 실습에서 |
|---|---|---|
| **y** | 원하는 결과물: 출력 형식(docx, hwpx, html, pdf …) + 내가 원하는 출력 형태 | A4 2쪽 가정통신문.hwpx, 공문목록.xlsx, 주간업무보고.hwpx |
| **x** | 입력값: 파일(hwpx, docx, pdf, jpg …) + 내가 원하는 조건과 형태 | 운영계획서.hwpx, 공문 폴더 |
| **a, b** | x를 y로 만드는 방법과 경향 = **스킬** | SKILL.md + 양식(assets) + 도구(scripts) |

> 바이브 코딩이란 y, x, a, b를 내가 필요에 따라 정하고 처리하는 과정입니다.

## 실습 자료 안내

- 공문은 모두 **실습용 가상 공문**입니다. 기관과 학교는 `OO교육지원청`, `OO학교` 로 표기했습니다.
- 기본 실습 자료는 담당 교사와 협력 교사를 제외하고 모두 익명화했습니다. 기본 실습 이후에는 본인 자료로 바꿔 실습하세요.
- 실제 학생·교직원 개인정보는 넣지 마세요. 자세한 내용은 [`00_시작하기/3_안전수칙.md`](00_시작하기/3_안전수칙.md).
- `skills/*/scripts/hwpx_tool.py` 는 hwpx 양식의 구조를 건드리지 않고 `{{빈칸}}` 만 채우는 보조 도구입니다. 스킬이 알아서 사용합니다.
