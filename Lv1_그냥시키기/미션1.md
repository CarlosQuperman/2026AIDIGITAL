# 미션 1. 그냥 시켜 보기 (Lv.1 · 제한 시간 8분)

스킬 없이 프롬프트만으로 같은 일을 세 번 시키면 어떻게 될까요?

## 준비
- Cowork 작업 폴더: `2026AIDIGITAL-main` 전체
- 입력 파일: `가정통신문/2026학년도 AI·SW 꿈키움 현장체험학습 운영계획(넷마블 게임 박물관) .hwpx`

## 순서
1. Cowork에서 **새 작업(새 대화)** 을 열고 아래 문장을 그대로 보냅니다.

```
가정통신문 폴더의 넷마블 게임 박물관 운영계획서를 읽고, 학부모용 가정통신문으로 만들어 줘.
결과 파일은 Lv1_그냥시키기/output 폴더에 저장해 줘.
```

2. **새 대화를 열어** 같은 문장을 다시 보냅니다. 이렇게 모두 **3번** 반복합니다.
   - 같은 대화에서 이어서 요청하면 앞의 결과를 따라 하므로 차이가 잘 드러나지 않습니다.
3. 세 결과를 나란히 열어 [`결과비교표.md`](결과비교표.md) 를 채웁니다.

## 완료 조건
- [ ] 결과 파일 3개가 `output/` 에 있다.
- [ ] 세 결과의 차이점을 3가지 이상 찾았다.

## 생각해 볼 질문
- 왜 매번 형식·분량·말투가 다를까요?
- 운영계획서에 없는 내용(제출 기한, 연락처 등)을 지어 넣은 결과가 있나요?
- 학교 가정통신문 양식(`가정통신문/` 폴더의 참가 신청서)과 얼마나 다른가요?

> 에이전트는 기준을 모르면 매번 추측합니다. 기준을 적어 주는 것이 **스킬**입니다. → [Lv.2](../Lv2_스킬만들기/미션2.md)
