# 미션 4. 공문 해결사 — 스킬 3개 잇기 (Lv.4 · 제한 시간 12분)

스킬 하나는 단순하지만, 세 개를 이으면 **업무 흐름**이 됩니다.

```
input/ (가상 공문 10건)
   → ① gongmun-organizer : 공문 정리   → output/공문목록.xlsx
   → ② todo-extractor    : 할 일 추출   → output/이번주_할일.md
   → ③ weekly-report     : 보고 초안    → output/주간업무보고.hwpx
```

## 준비
1. 먼저 [`폴더규칙.md`](폴더규칙.md) 를 읽습니다(3분).
2. `skills/` 의 zip 3개를 모두 **Customize → Skills** 에 올립니다.
   - `gongmun-organizer.zip`, `todo-extractor.zip`, `weekly-report.zip`
3. Cowork **새 작업**을 열고 작업 폴더를 **`Lv4_스킬연결`** 로 지정합니다.

## 실행 — 한 줄 지시
```
기준일은 2026. 11. 2.(월)이야.
gongmun-organizer → todo-extractor → weekly-report 순서로 실행해서 input 폴더의 공문을 처리해 줘.
```

- 각 SKILL.md 끝의 **'다음 단계'** 덕분에 "공문 정리해 줘" 한마디로도 이어서 실행될 수 있습니다. 두 방법을 모두 시험해 보세요.

## 완료 조건
- [ ] 한 번의 지시로 결과 파일 3개가 `output/` 에 생겼다.
- [ ] `input/` 원본 10개는 그대로다(수정·삭제 없음).
- [ ] `log.md` 에 처리 건수와 실패 이유가 적혀 있다.

## 확인해 볼 점
- 공문목록.xlsx의 마감일 10개가 원본 공문과 같나요? (2~3개만 직접 열어 대조)
- 이번 주 마감이 몇 건인가요? 주간업무보고에 마감 임박 순으로 들어갔나요?
