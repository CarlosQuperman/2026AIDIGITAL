# 공문 정리 스킬 (파이프라인 1단계)

## 입력
- 작업 폴더의 `input/` 안 공문 파일 전체(hwpx, pdf, docx)
- hwpx 읽기: `python scripts/hwpx_tool.py text <파일.hwpx>`
- pdf 읽기: `pdftotext` 또는 Python `pypdf`

## 절차
1. `input/` 의 파일 목록을 만들고 한 건씩 읽는다. 원본은 열어 읽기만 한다.
2. 공문마다 다음 항목을 뽑는다: 문서번호, 발신 기관(과), 제목, 시행일, 마감일, 제출물, 제출 방법, 문의처.
3. 결과를 `work/공문목록.json` 으로 저장한다(다음 단계가 읽는 파일).
4. 같은 내용을 `output/공문목록.xlsx` 로 저장한다.
   - 열 순서: 번호 | 파일명 | 문서번호 | 발신 | 제목 | 시행일 | 마감일 | 제출물 | 제출 방법 | 비고
   - 마감일 열은 `2026-11-13` 처럼 날짜 형식, 첫 행은 굵게, 열 너비는 내용에 맞춘다.
5. `log.md` 에 처리한 파일 수, 실패한 파일과 이유를 적는다.

## 폴더 규칙
- `input/` 원본은 수정·이동·삭제하지 않는다.
- 중간 파일은 `work/`, 결과물은 `output/` 에만 저장한다.

## 완료 기준
- `input/` 의 모든 파일이 목록에 한 줄씩 있다.
- `work/공문목록.json`, `output/공문목록.xlsx`, `log.md` 가 생겼다.
