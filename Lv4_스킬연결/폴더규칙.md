# 안전한 일괄 처리를 위한 폴더 규칙

일괄 처리는 한 번 잘못되면 수십 개 파일이 한꺼번에 망가집니다. 아래 4가지를 SKILL.md에 그대로 넣습니다.

| 폴더·파일 | 역할 | 규칙 |
|---|---|---|
| `input/` | 원본 · 읽기만 | 원본은 수정·삭제 금지. 에이전트는 input/을 읽기만, 작업은 복사본으로 |
| `work/` | 중간 작업 파일 | 다음 단계가 읽을 파일(예: `공문목록.json`)을 둔다 |
| `output/` | 결과물만 저장 | 어디에 무엇이 생겼는지 항상 한 곳에서 확인. 처리 못 한 파일은 '확인 필요' 목록으로 분리 |
| `log.md` | 처리 기록 | 몇 건 처리·실패·이유를 남긴다 |

## 파일명 규칙
`날짜_업무명_버전` — 예: `20261030_공문목록_v1.xlsx`
- 다시 만들면 v2, v3으로 올리고 이전 버전은 지우지 않는다. (Lv.6 완성 패키지에서 적용)

## SKILL.md에 넣을 문장(복사해서 쓰기)
```markdown
## 폴더 규칙
- input/ 원본은 수정·이동·삭제하지 않는다.
- 중간 파일은 work/, 결과물은 output/ 에만 저장한다.
- 처리하지 못한 파일은 '확인 필요' 목록으로 분리해 사람에게 알린다.
- log.md 에 처리 건수, 실패 건수와 이유를 남긴다.
```
